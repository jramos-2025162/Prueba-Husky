# Actividad No. 4 - Mini App con Control de Calidad (Husky y ESLint)

## Descripción del Proyecto
Mini aplicación web desarrollada en JavaScript Vanilla que consume una API pública de forma asíncrona (`fetch`) y presenta una interfaz con buscador en tiempo real. El proyecto cuenta con control de calidad de código mediante **ESLint** y ganchos automáticos de pre-commit con **Husky**.

---

## Tecnologías Utilizadas
- **HTML5 & CSS3:** Estructura y diseño adaptable.
- **JavaScript (ES6+):** Lógica, consumo de API (`fetch`) y manipulación del DOM.
- **Git & GitHub:** Control de versiones y repositorio remoto.
- **ESLint:** Herramienta de análisis estático para asegurar buenas prácticas de programación.
- **Husky:** Automatización de ganchos Git (pre-commit hook para bloquear commits con errores de estilo).

---
